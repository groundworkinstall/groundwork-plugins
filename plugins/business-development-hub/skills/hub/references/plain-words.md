# Plain words

Swap these out unless the owner uses them in their own writing.

| Avoid | Write instead |
|---|---|
| delve, dive into | look at, go through |
| leverage, utilize | use |
| robust, comprehensive | full, complete, or say what it covers |
| seamless | smooth, or say what doesn't break |
| crucial, vital, pivotal | important, or say why it matters |
| navigate | handle, work through |
| elevate, unlock, empower | say what actually gets better |
| foster | build, help |
| streamline | make faster, cut steps |
| journey | process, the months ahead |
| landscape, realm, tapestry | field, area, or name it |
| game-changer, transformative | say what changes |
| cutting-edge, best-in-class, world-class | say what it does |
| holistic | whole, all of it |
| meticulous | careful |
| synergy | working together |
| notably, importantly | cut it |
| moreover, furthermore, additionally | also, and, or start a new sentence |
| in today's fast-paced world | cut it |
| I hope this email finds you well | start with the point |

Shapes to avoid:
- "It's not X, it's Y."
- Three short fragments in a row.
- Every list in threes.
- Paragraphs all the same length.
- Asking a question and answering it yourself.
- Praising the thing you're writing about.
- A closing line that sums up what was just said.
- The long dash. Use a comma, a colon, a period or parentheses.
