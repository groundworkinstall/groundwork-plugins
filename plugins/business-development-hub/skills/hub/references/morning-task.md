# The morning task

One scheduled task per owner, named "Hub morning", weekdays (Monday to Friday) at 7:00am in the owner's own time zone, made with the app's scheduled task tool and run once right after it's made, so today's Hub Today exists. A second owner gets "Hub morning «name»" at 7:15am. No other scheduled task: Friday review is never scheduled; the owner types it. Let the app ask the owner to allow it; H18 says to click Allow.

Its prompt, with the fill-ins replaced (business name, time zone, Hub home page name, asks a week, first name). Words inside « » are fill-ins.
